# HumanDataScience

Sono stati realizzati due notebook a supporto del caso studio riguardante le differenze salariali nei principali campionati calcistici.
Il primo, denominato primaResearchQuestion, contiene tutti i test statistici e le implementazioni effettuate per rispondere alla prima domanda di ricerca: verificare l'esistenza di differenze salariali significative tra i diversi campionati.
Il secondo, denominato secondaResearchQuestion, raccoglie le analisi e i test condotti per affrontare la seconda domanda: analizzare in che modo i campionati risultano influenzati da variabili strutturali e come queste differiscono tra loro.
